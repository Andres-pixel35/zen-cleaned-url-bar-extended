# URL bar about:config preferences asked by configure.sh.
#
# Every bool and choice preference listed here is also exposed in preferences.json
# (Zen Settings > Mods); integer preferences only live here because Zen's mod
# settings page can't edit numbers (tests/test_consistency.py checks both stay in sync).
#
# Line formats (fields separated by "|", no "|" allowed inside a field):
#   @section|<title>|<description>
#   @renamed|<old pref>|<new pref>
#   <kind>|<pref>|<zen default>|<depends on>|<question>|<help>|<choices>|<since>
#
#   kind     bool, int or choice (choice = string preference with fixed values).
#   default  Zen 1.23 default. Only used for display: "reset" removes the user value.
#   depends  Optional pref that must be true (or false when prefixed with "!") for
#            the question to make sense; otherwise the question is skipped.
#   choices  For choice (and optionally int): value=Label;value=Label
#   since    Revision of this list that added the question. Give a new question the
#            current highest revision + 1: update.sh offers questions newer than the
#            revision the user last saw (stored in mod.cleanedurlbarext.questions-seen).
#
# @renamed: when Zen renames a preference, keep the question under the new name and
# add a line here; the scripts move the user's saved value to the new name.
